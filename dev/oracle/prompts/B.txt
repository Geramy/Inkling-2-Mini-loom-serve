The history of computing is a story of steady abstraction. Early machines were programmed by physically rewiring circuits, and a single calculation could take days of preparation. The stored program concept changed this: instructions and data lived in the same memory, so a machine could be reprogrammed simply by loading new contents. Assembly languages followed, giving mnemonic names to machine operations, and then compilers allowed engineers to describe algorithms in terms closer to mathematics than to hardware. Each layer hid detail from the layer above, and each layer made a new class of programs affordable to write. Operating systems learned to share one processor between many tasks, networks connected machines into larger systems, and databases gave durable structure to information. In recent years, graphics processors originally built for rendering images turned out to be excellent at the dense linear algebra that underlies neural networks. Training large models on these devices requires careful attention to memory bandwidth, numerical precision, and the way work is divided across thousands of parallel threads. Inference has its own constraints: the weights must be streamed from memory for every generated token, so the speed of a single user is bounded by bandwidth rather than arithmetic. Quantization shrinks the weights to a few bits each, trading a small loss in accuracy for a large gain in speed. Mixture of experts models go further by activating only a small fraction of their parameters for each token.
